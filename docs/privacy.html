Privacy Policy

Last updated: November 17, 2026

Overview

Red Crow For Safari enhances your video watching experience. Settings are stored on your device. Optional community features make requests to third-party providers as described below.

Data Collection

Red Crow has no developer-operated analytics or tracking service and requires no Red Crow account. Specifically:

  • No developer-operated analytics or tracking
  • No Red Crow account or sign-in required
  • Features such as watched-video indicators and position memory store video-related state locally
  • Red Crow does not set its own tracking cookies; website and provider practices remain subject to their policies
  • Optional provider requests disclose the identifiers and network information described below

Local Storage

Settings, preferences, and feature state are stored locally using browser storage. This includes saved playback positions and watched-video state when those features are enabled. Settings can also be exported by you.

Third-Party Services

When you enable specific features, the extension may connect to the following services:

  • SponsorBlock (sponsor.ajay.app) retrieves community-reported segments using a short prefix of a hash of the video ID and requested categories. On browsers without the required cryptographic API, the fallback sends the video ID directly.
  • Return YouTube Dislike (returnyoutubedislikeapi.com) receives the video ID to return estimated dislike counts and ratios. These figures use archived data and community-based estimates; they are not official current YouTube counts. Red Crow does not submit your votes to this service.
  • DeArrow (sponsor.ajay.app and dearrow-thumb.ajay.app) receives video IDs to retrieve community-submitted titles and thumbnails.
  • 7TV, BetterTTV, FrankerFaceZ receive requests for global or channel-specific emotes and image assets; channel lookups include the channel identifier.
  • YouTube receives optional title/category metadata requests. In version 1.9 and later, these contain the video ID, language, and generic protocol client name/version, omit credentials and referrer, and do not copy visitor or account context. Earlier releases may use site-provided context and browser-default credentials and referrer behavior. YouTube still receives ordinary connection metadata and processes requests under Google's privacy policy.

These connections occur when the related feature is enabled. Like other internet requests, they expose your IP address and ordinary network request information to the provider. Providers may retain request metadata for security and analytics under their own policies. Disabling the related feature stops subsequent feature lookups; it does not undo requests already sent.

According to Return YouTube Dislike's security FAQ, raw IP addresses remain in memory and hashes are stored for abuse prevention and aggregate analytics, not sold or used for advertising. This is the provider's stated practice, not a guarantee that requests leave no record.

See the providers' policies for their processing practices: SponsorBlock, DeArrow, 7TV, BetterTTV, and FrankerFaceZ. These policies may cover provider accounts and features that Red Crow does not use; Red Crow's integrations do not submit votes. Version 1.9's optional metadata requests do not include your YouTube account identifier.

Permissions

  • storage, saves your preferences locally on your device.
  • activeTab, applies your settings to the current tab.
  • Host permission (youtube.com), allows the extension to run on video pages.

Children's Privacy

Red Crow does not operate an account or analytics service for children. Optional third-party requests follow the same behavior described above.
